# Local service ports

Default port mappings:

| Service | Host address | Container port |
| --- | --- | --- |
| Backend API | `http://localhost:5283` | `8080` |
| PostgreSQL | `localhost:5434` | `5432` |
| SeaweedFS S3 | `http://localhost:8333` | `8333` |
| OCR worker | `http://localhost:8000` | `8000` |
